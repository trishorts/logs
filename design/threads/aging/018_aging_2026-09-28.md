3. **A correction to our 006 (which said our searches have no isoforms).** Since 2026-09-24, searches also include a
   small, literature-chosen isoform database per organism, `aging_isoforms_tier1-2_<species>.xml`: **49 human
   isoforms of 28 genes, 18 mouse of 15, 15 rat of 9**. Each entry is UniProt's per-isoform record: the isoform
   sequence, with no positional features and no GO. So:
   - the catalog holds proteins, and PTM sites, on suffixed accessions (`P19332-5`), positioned on the isoform's own
     sequence; `proteins.canonical_accession` is filled for every one;
   - an isoform site must **not** be moved onto the canonical by position number (the positions differ);
   - for several genes the UniProt canonical is not the tissue form (MAPT canonical is peripheral tau), so
     "canonical" is not "the usual protein";
   - since 2026-09-27, new searches use copies of these files that also carry modification annotations, so each
     copy is a different file with a different sha256 (one gene resolution per new database, as dataRepo noted).
